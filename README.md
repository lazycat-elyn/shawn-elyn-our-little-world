## 放进 StackBlitz
1. 解压 ZIP
2. Ctrl+A 选中 `index.html`, `styles.css`, `app.js`, `assets`
3. 拖进 StackBlitz 左边 FILES
4. 全部选择 Replace / Overwrite
5. 不需要 npm install；静态项目可直接运行
