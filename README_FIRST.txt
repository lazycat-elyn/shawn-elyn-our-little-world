MASTER 2.7 — CAR GAMEPLAY 2.0

基于已经修好的 MASTER 2.6.2 人物版本继续。

本 Patch 只更新 Car Gameplay。

新增/升级：
- 轻松 / 标准 / 挑战 3 种驾驶难度
- 所有 Go Out 地点继续可用 Lexus 驾驶前往
- 每条路线有不同限速、道路类型与车流强度
- 新 HUD：限速、车道位置、跟车距离、ETA
- 新道路事件：学校区域、骑行者、急救车、坑洞
- 保留红灯、测速、减速带、慢车、行人、施工、汇流、转弯、下雨
- 评分加入：车道保持、限速控制、跟车距离
- Parking 2.0：更慢更精确、停车雷达、TOP/REVERSE camera、难度容差
- 保留上车、车门、安全带、START、AC、音乐、车窗、车灯、雨刷、喇叭、D/R、手刹、加油、洗车、后备箱、保养
- 黑色 Lexus W 8331 M 与白色 Lexus SLWR 0309 不变
- 不修改 Fishing / Fridge / Recipe / Wardrobe / Go Out activities / Pets / Tasks
- 不修改 MASTER 2.6.2 clean character sprite mode

1. 解压 ZIP。
2. 打开 MASTER270_CAR_GAMEPLAY_2_0。
3. Ctrl+A → Ctrl+C。
4. 贴入 shawn-elyn-our-little-world。
5. Replace。
6. GitHub Desktop Summary: MASTER 2.7 Car Gameplay 2.0
7. Commit to main。
8. Push origin。
